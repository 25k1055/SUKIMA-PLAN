SUKIMA PLAN（アプリ版）

■ フォルダの中身
  ai_project.html        アプリ本体
  index.html             ai_project.html への入口
  manifest.webmanifest   アプリ情報（名前・アイコン・色）
  sw.js                  オフライン用の仕組み（Service Worker）
  icon-*.png             アイコン

■ 注意
  アプリとしてインストールするには HTTPS で公開されたURL（または localhost）で開く必要があります。
  ファイルをダブルクリックして開く方法（file://）でも普通に使えますが、インストールとオフライン保存の仕組みは働きません。

■ パソコンで試す（localhost）
  1. このフォルダでターミナルを開く
  2. python3 -m http.server 8000
  3. Chrome で http://localhost:8000/ を開く
  4. アドレスバー右端のインストールアイコン → インストール

■ スマホにインストールする
  1. このフォルダごと、無料のホスティング（Netlify Drop / GitHub Pages / Cloudflare Pages など）にアップロード
  2. 発行された https:// のURLをスマホで開く（1回開けばオフラインでも起動できます）
  3. Android(Chrome): メニュー → 「アプリをインストール」または「ホーム画面に追加」
     iPhone(Safari): 共有ボタン → 「ホーム画面に追加」

■ 更新するとき
  ai_project.html を差し替え、sw.js の V（'sukima-plan-v3'）を v2, v3… に変えてアップロード。

■ データについて
  予定などの保存先はブラウザ内で、開くURLごとに別になります。
  ファイル版から公開URL版へ移すときは、☰メニューの「保存」→ 新しい方で「読込」を使ってください。

■ 招待（予定の共有）と共通の空き
  サーバーやアカウントは使いません。招待コードを相手に直接送る方式です。
  1. 👥 → 名前を入れて「招待コードを作る」→ 📤 で LINE・メールなどに送る（📋 はコピー）
  2. 受け取った人は 👥 →「コードを貼り付け」→ 読み込む（または 📁 でファイルを選ぶ）
  3. 画面上部の名前タブで「自分 / 相手」の月・週・日の表示を切り替え（相手の予定は閲覧のみ）
  4. 相手を見ている間、④の欄に「共通の空き」が出ます。🔍 から曜日・時間帯・長さ・期間を指定できます
  ・公開内容は「空き時間のみ」（予定名は「予定あり」）か「予定名も」を選べます。🔒を付けた予定は名前を隠します
  ・コードは送った時点の予定です。更新したいときは、もう一度コードを作って送ってください（同じ人なら上書きされます）
  ・コードを受け取った人は、その人の端末の中で相手の予定を見られます。転送された場合はコードを持つ人なら読み込めるので、送る相手に注意してください

■ データの移行・書き出し
  ☰ → 📤 共有シートから Google Drive・iCloud・LINE などへ保存 ／ 💾 ダウンロード ／ 📥 読込
  📅 .ics は Googleカレンダー・iPhoneカレンダーなどに読み込める形式です
